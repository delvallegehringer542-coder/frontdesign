# 02 - CSS 样式美化与现代布局 (CSS3 Styling & Layout)

欢迎来到第二课！在第一课中，我们掌握了 HTML 骨架（骨骼）；这一课我们将学习 **CSS**（皮肤与衣着），把朴素的网页打造成现代化、高颜值的交互界面。

---

## 📚 本课核心知识点导航

1. **CSS 三大引入方式与核心选择器**
   - 外部样式表、内部 `<style>` 标签、行内样式
   - 标签选择器、类选择器 (`.class`)、ID 选择器 (`#id`)
2. **盒模型 (The Box Model) —— 前端排版灵魂**
   - `Margin` (外边距)：元素与外界的距离
   - `Border` (边框)：元素的轮廓线
   - `Padding` (内边距)：元素内容到边框之间的留白
   - `Content` (内容区)：`width` 与 `height`
   - ⭐ **必背关键属性**：`box-sizing: border-box`
3. **Flexbox 弹性盒子布局 —— 排版神器**
   - 容器属性：`display: flex`、`justify-content`、`align-items`、`flex-direction`、`gap`
4. **CSS 伪类与动效**
   - `:hover` 鼠标悬停动效、`:active` 点击反馈、`transition` 平滑过渡
